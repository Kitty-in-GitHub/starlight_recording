# 宣传与媒体

从明确活动信息开始，再完成文案、排版、审核和发布。

## 按任务查找

| 要做的事情 | 内容入口 |
| --- | --- |
| 写一份活动、会议或材料提交通知 | [通用通知模板](../Template/Notice_Template.md) |
| 准备燃藜活动公告 | [燃藜活动通知模板与历史示例](../Template/ranli_Template.md) |
| 撰写和排版微信公众号推文 | [推文撰写与排版](../WriteWeChatTweet.md) |
| 申请帮推或 LED 投稿 | [帮推投稿指南](../TheDepartmentOfLove/PublicityHelper.md) |
| 发布到资料站 | [网站文章发布](../GitHubWebsiteMaintenance.md) |

## 发布前核对

- 活动名称、面向对象、时间、地点和参与方式是否完整。
- 报名及附件链接是否能打开，截止时间是否清楚。
- 文案、图片和署名是否已经确认，是否已由对应负责人审核。
- 不同渠道的时间、地点、规则是否一致。

发布后保留正式通知地址和宣传成品。安排有变时更新原通知，并记录变更时间与内容。

## 仍待补充

各宣传渠道的维护人和审核人、投稿提前量、头尾图与标识素材、可使用素材的来源说明，以及通知变更的联络方式。

素材入口统一收录到[资料中心](../resources/index.md)，本学期具体人员见[负责人及分工](../../home/semester/people.md)。
