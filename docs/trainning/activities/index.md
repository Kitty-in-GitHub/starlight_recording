# 活动举办

先阅读[活动全流程](../TheDepartmentOfLove/TheFullProgressOfHoldingClubActivities.md)，确认本次活动涉及哪些环节，再进入对应指南。

## 按环节查找

| 环节 | 要明确的事情 | 指南与资料 |
| --- | --- | --- |
| 策划与分工 | 活动内容、时间地点、人员和工作量 | [活动全流程](../TheDepartmentOfLove/TheFullProgressOfHoldingClubActivities.md)、[岗位职责](../BeYourself.md) |
| 计划书与立项 | 所需材料、申请渠道和审核要求 | [活动计划书](../Template/PlanningProposal_Template.md)、[制度与校方文件](../resources/policies.md) |
| 场地与准备 | 场地是否落实、人员与物料是否到位 | [借教室](../TheDepartmentOfLove/BorrowClassroom.md)、[经费与物资](../finance/index.md) |
| 宣传与报名 | 面向对象、报名方式、截止时间 | [宣传与媒体](../publicity/index.md)、[通知模板](../Template/Notice_Template.md) |
| 现场执行 | 主持、签到、拍照、秩序与奖品发放 | [活动全流程](../TheDepartmentOfLove/TheFullProgressOfHoldingClubActivities.md) |
| 结项与整理 | 二课分、材料交付、总结与归档 | [结项与二课分](closing.md)、[活动档案](../resources/archives.md) |

## 筹备前确认

- 谁是活动负责人，哪些任务由哪些人完成？
- 哪些日期已经确认，哪些仍是计划？
- 是否需要申请场地、经费、宣传资源或二课分？
- 用哪些模板，活动结束后需要交付哪些材料？

## 仍待补充

立项平台的具体操作、现场岗位清单、活动变更或取消的处理方式，以及不同类型活动的结项要求。
